# Quadrant Todo

Personal todo app that visualizes tasks by importance and urgency in a 4-quadrant
matrix.

## Features
- Add tasks with title, notes, due date, importance, and urgency
- Today list and overdue indicators
- Drag and drop tasks between quadrants
- Edit, complete, and delete tasks
- Data stored locally in your browser (localStorage)

## Run locally
Open `index.html` in your browser.

## Notes
- High/low thresholds are set at 3 (1-5 scale).
- Dragging a task to a quadrant sets importance/urgency to 4 (high) or 2 (low).
